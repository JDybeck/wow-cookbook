# The Cookbook

A World of Warcraft: **Forever** addon for looking up every profession recipe in game: skill levels (learn / yellow / green / gray), reagents with have/need counts, where to learn it, required tools, and a calculator for batch crafting and leveling.

Type `/cookbook` (or `/cb`) in game.

## Install

Copy the [`Cookbook`](Cookbook) folder to:

```
World of Warcraft\_forever_\Interface\AddOns\Cookbook
```

Full usage, the skill-up math and data sources are in [Cookbook/README.md](Cookbook/README.md).
